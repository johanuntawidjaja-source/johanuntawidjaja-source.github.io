MediSync

A medication-reminder concept for older adults, pairing a web platform with a physical buzzer.

My role

Tools & approach

ESP32 · Web application · Team prototyping

When / Status

September 2025
Partial prototype

01

A reminder beyond the phone.

The team proposed a web platform for medication and appointment reminders, connected to an ESP32 device for older adults who might not use a smartphone. I helped use AI to build the prototype and present it at the SEVEN-organised MVP Hackathon.

02

What the demonstration actually did.

The device buzzed, but the intended web-to-device reminder flow did not work as proposed. We suspected a memory constraint; that explanation was not confirmed. The result was a partial demonstration, with the integration still unresolved.
